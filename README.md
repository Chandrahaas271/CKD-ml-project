# Chronic Kidney Disease Prediction

## Project Overview
This project predicts Chronic Kidney Disease (CKD) using Machine Learning
based on medical parameters.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Google Colab

## Dataset
- Source: UCI Machine Learning Repository
- Records: 400 patients

## ML Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## Results
- Achieved good accuracy in predicting CKD

## How to Run
1. Open `CKD_Prediction.ipynb`
2. Upload dataset if needed
3. Run all cells
