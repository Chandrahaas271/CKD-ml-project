# Chronic Kidney Disease Prediction System

A Machine Learning based healthcare prediction system that predicts the possibility of Chronic Kidney Disease (CKD) using patient medical parameters.

The project applies data preprocessing, feature engineering, and classification algorithms to analyze clinical data and provide accurate disease predictions.

---

## 🚀 Features

- Chronic Kidney Disease Prediction
- Medical Data Preprocessing
- Missing Value Handling
- Feature Encoding and Scaling
- Machine Learning Classification Models
- Model Performance Evaluation
- Accuracy Based Prediction System
